# Описание проекта Habit Tracker

## Обзор
Habit Tracker - это полнофункциональное веб-приложение, предназначенное для помощи пользователям в развитии и поддержании положительных привычек через отслеживание, аналитику и социальные функции. Приложение следует современным методам разработки с архитектурой микросервисов с использованием контейнеров Docker.

## Архитектура
- **Фронтенд**: React 18 + TypeScript + Vite + TailwindCSS
- **Бэкенд**: Go (Golang) с базой данных PostgreSQL
- **Контейнеризация**: Docker и Docker Compose
- **Аутентификация**: Аутентификация на основе JWT
- **Управление состоянием**: Zustand для управления состоянием фронтенда
- **Стилизация**: TailwindCSS с темной темой по умолчанию

## Ключевые особенности

### 1. Управление пользователями
- Функционал регистрации и входа в систему
- Аутентификация на основе JWT, хранящаяся в localStorage
- Управление профилем пользователя

### 2. Отслеживание привычек
- Создание, просмотр и управление личными привычками
- Отслеживание ежедневного прогресса с функцией отметки
- Визуальные индикаторы прогресса

### 3. Панель аналитики
- Визуализация данных с использованием Recharts
- Отслеживание прогресса со временем
- Статистика выполнения привычек

### 4. Социальные функции
- Система друзей для связи с другими пользователями
- Возможность делиться привычками и прогрессом с друзьями
- Функции социальной ответственности

### 5. Детальные представления привычек
- Индивидуальные страницы для каждой привычки
- Исторические данные и тенденции
- Детальная информация и статистика

## Технологический стек

### Фронтенд технологии
- **React 18**: Разработка пользовательского интерфейса на основе компонентов
- **TypeScript**: Разработка безопасного JavaScript с типами
- **Vite**: Быстрый инструмент сборки и сервер разработки
- **TailwindCSS**: CSS-фреймворк с утилитарным подходом
- **React Router v6**: Маршрутизация на стороне клиента
- **Zustand**: Легковесное управление состоянием
- **Recharts**: Библиотека визуализации данных
- **Lucide React**: Библиотека иконок
- **Date-fns**: Утилиты для работы с датами

### Бэкенд технологии
- **Go (Golang)**: Высокопроизводительный язык для бэкенда
- **PostgreSQL**: Управление реляционной базой данных
- **JWT**: Безопасная аутентификация на основе токенов
- **Golang Migrate**: Инструмент миграции базы данных
- **Godotenv**: Управление переменными окружения
- **Lib/pq**: Драйвер PostgreSQL для Go

### Инфраструктура
- **Docker**: Контейнеризация для согласованного развертывания
- **Docker Compose**: Оркестровка многоконтейнерных приложений
- **Nginx**: Веб-сервер для доставки фронтенда

## Схема базы данных
Приложение использует PostgreSQL со следующими основными таблицами:
- `users`: Хранит информацию об учетных записях пользователей
- `habits`: Содержит созданные пользователем привычки
- `habit_history`: Отслеживает ежедневное выполнение привычек
- `friends`: Управляет дружескими связями пользователей

## Развертывание
Приложение предназначено для контейнерного развертывания с использованием Docker Compose, который оркестрирует три сервиса:
1. **Фронтенд**: Обслуживает приложение React
2. **Бэкенд**: Запускает сервер API на Go
3. **База данных**: Сервис базы данных PostgreSQL
